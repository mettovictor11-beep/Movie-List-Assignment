# Movie List App

A simple React application that displays a list of movies and allows users to add and delete movies dynamically.

## Features

- Display movies using an array of objects
- Render movies dynamically using `.map()`
- Component-based React structure
- Add new movies
- Delete movies
- React state management using `useState`
- Responsive CSS layout

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- Git & GitHub
